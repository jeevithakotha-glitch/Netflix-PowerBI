Netflix Dashboard | Power BI

Project Overview

This project presents an interactive Netflix dashboard built using Microsoft Power BI to analyze Netflix movies and TV shows. It provides insights into content distribution, genres, release years, ratings, and other key metrics.

Objectives

- Analyze the distribution of movies and TV shows.
- Explore content trends over time.
- Identify popular genres and content ratings.
- Present key insights through interactive visualizations.

Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV Dataset

Dataset

The project uses a Netflix titles CSV dataset containing information about movies and TV shows, such as title, director, cast, country, release year, rating, duration, and genre.

Dashboard Features

- Total movies and TV shows
- Movies vs. TV shows comparison
- Content distribution by rating
- Genre analysis
- Content trends by release year
- Interactive charts and filters

How to Use

1. Download or clone this repository.
2. Open the ".pbix" file using Microsoft Power BI Desktop.
3. If necessary, update the CSV data source path.
4. Refresh the dataset to load the data.
5. Explore the dashboard and its interactive visuals.

Key Learnings

- Data cleaning and transformation
- Data modeling and visualization
- Creating interactive reports in Power BI
- Extracting insights from datasets
